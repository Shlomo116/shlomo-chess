# ♞ שח־מט · Chess Royale

אתר שחמט בעברית עם חיבור ישיר בין מכשירים — שחקו מול חבר מכל מקום בעולם, בלי הרשמה ובלי שרת משחק.

![סטטוס](https://img.shields.io/badge/build-vite%20%2B%20react-informational)

## מה יש כאן

| תכונה | פירוט |
| --- | --- |
| **משחק מול חבר** | חדר פרטי עם קוד בן שש ספרות. החיבור עובר **ישירות בין הדפדפנים** (WebRTC / PeerJS) — גם כששני השחקנים ברשתות שונות. |
| **משחק מול המחשב** | מנוע Stockfish 11 (WebAssembly) שרץ בתוך הדפדפן. שבע רמות קושי. |
| **שני שחקנים על מסך אחד** | הלוח מסתובב אוטומטית בין התורות. |
| **שעונים** | בזק / בליץ / רפיד / קלאסי, כולל תוספת זמן, עם התראה ויזואלית כשנגמר הזמן. |
| **צ׳אט בזמן אמת** | הודעות עוברות באותו ערוץ P2P כמו המהלכים. |
| **רשימת מהלכים** | סימון פיגורין, ניווט קדימה ואחורה (גם בחצי המקלדת) וייצוא PGN. |
| **עיצוב** | ערכה כהה ויוקרתית, RTL מלא, אנימציות, צלילים מסונתזים, ותמיכה מלאה בנייד. |

## איך החיבור בין המכשירים עובד

1. שחקן א׳ פותח חדר ומקבל קוד (למשל `K7M2QX`) וקישור הזמנה.
2. שחקן ב׳ מזין את הקוד או פותח את הקישור.
3. שרת ה־signaling הציבורי של PeerJS מבצע "לחיצת יד" בין הדפדפנים — ומרגע זה **כל המהלכים עוברים ישירות**, בלי שרת באמצע.
4. אם NAT נוקשה חוסם חיבור ישיר, התעבורה עוברת דרך שרתי TURN ציבוריים חינמיים, כך שהמשחק עובד גם ברשתות סלולריות ובמשרדים.

אם החיבור נופל באמצע משחק, האורח מנסה להתחבר מחדש אוטומטית והמארח שולח את מצב הלוח המלא לסנכרון.

## הרצה מקומית

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # בנייה לפרודקשן -> dist/
npm run preview  # תצוגה מקדימה של הבנייה
```

## פריסה ל-Vercel

הפרויקט מוכן לפריסה כמות שהוא: `Framework Preset = Vite`, `Build Command = npm run build`, `Output Directory = dist`.
הקובץ `vercel.json` כבר מגדיר את הכל, כולל כותרות caching למנוע השחמט.

## מבנה הפרויקט

```
src/
  App.tsx                 # ניהול המסכים, המצב והחיבור בין החלקים
  lib/
    useChessGame.ts       # מצב המשחק: חוקים (chess.js), שעונים, היסטוריה, תוצאה
    net.ts                # שכבת P2P מעל PeerJS + הגדרות STUN/TURN
    engine.ts             # עטיפת UCI ל-Stockfish ב-Web Worker
    sound.ts              # צלילים מסונתזים ב-WebAudio (בלי קבצי אודיו)
    utils.ts              # בקרות זמן, רמות קושי, פורמט שעון, סימון פיגורין
  components/             # לוח, שורות שחקנים, רשימת מהלכים, צ׳אט, לובי, טוסטים
public/engine/            # stockfish.js + stockfish.wasm
```
